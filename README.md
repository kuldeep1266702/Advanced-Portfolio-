# Kuldeep Sharma — Advanced Portfolio

## Included
- Responsive single-page portfolio
- Real-time animated particle background
- Animated cursor glow and scroll progress
- Scroll reveal animations
- Animated experience counters
- Light/dark theme toggle with localStorage
- Mobile navigation
- Resume download button
- Skills, experience, projects, achievements and contact sections
- Footer contact form with client-side validation and mailto handoff
- Resume source file in `assets/`

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Contact form
The form opens the visitor's default email client and prepares an email to `ks1266702@gmail.com`. For production hosting, replace the form handler with Formspree, Web3Forms, a serverless function, or your own backend if you want messages stored/emailed without requiring the visitor's mail client.

## Deploy
This static site can be deployed to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any normal web host.
